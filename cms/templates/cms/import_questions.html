Import Notes

  • Duplicate Detection: Questions with the same text in the same test will be skipped.
  • Test Creation: Tests are created based on the category field in each question.
  • Answers: The correct field should be the 0-based index of the correct answer.
  • Multiple States: You can upload a JSON array with multiple state objects.
